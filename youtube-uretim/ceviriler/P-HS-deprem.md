## Español (İspanyolca)

**Başlık:**
```
Por qué la red móvil se apaga horas después de un terremoto
```

**Açıklama (geçici):**
```
Tras un gran terremoto, muchas antenas móviles siguen funcionando durante un tiempo y luego se apagan. El motivo no es el temblor, sino las baterías. Así funciona la energía de respaldo de la red móvil.

Este canal lo hace alguien que trabaja dentro de un centro de operaciones de red móvil.
```

## Português – Brasil (Portekizce, Brezilya)

**Başlık:**
```
Por que a rede de celular cai horas depois de um terremoto
```

**Açıklama (geçici):**
```
Depois de um grande terremoto, muitas antenas de celular continuam funcionando por um tempo e depois se apagam. O motivo não é o tremor, são as baterias. É assim que funciona a energia de reserva da rede móvel.

Este canal é feito por alguém que trabalha dentro de um centro de operações de rede móvel.
```

## Deutsch (Almanca)

**Başlık:**
```
Warum das Handynetz Stunden nach einem Erdbeben ausfällt
```

**Açıklama (geçici):**
```
Nach einem großen Erdbeben arbeiten viele Mobilfunkmasten zunächst weiter – und fallen dann aus. Der Grund ist nicht das Beben, sondern die Batterien. So funktioniert die Notstromversorgung im Mobilfunknetz.

Dieser Kanal wird von jemandem gemacht, der in einem Betriebszentrum eines Mobilfunknetzes arbeitet.
```
