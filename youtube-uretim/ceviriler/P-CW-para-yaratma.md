## Español (İspanyolca)

**Başlık:**
```
Cómo crean dinero los bancos de la nada
```

**Açıklama (geçici):**
```
Cuando un banco te concede un préstamo, no presta el dinero de otro cliente: crea un depósito nuevo. Así explica el Banco de Inglaterra la creación de dinero y lo que significa para tus ahorros.

Este canal lo hace un ingeniero, no un banquero. Contenido educativo, no es asesoramiento financiero.
```

## Português – Brasil (Portekizce, Brezilya)

**Başlık:**
```
Como os bancos criam dinheiro do nada
```

**Açıklama (geçici):**
```
Quando um banco faz um empréstimo, ele não empresta o dinheiro de outro cliente: ele cria um novo depósito. É assim que o Banco da Inglaterra explica a criação de dinheiro — e o que isso significa para as suas economias.

Este canal é feito por um engenheiro, não por um banqueiro. Conteúdo educativo, não é aconselhamento financeiro.
```

## Deutsch (Almanca)

**Başlık:**
```
Wie Banken Geld aus dem Nichts erschaffen
```

**Açıklama (geçici):**
```
Wenn eine Bank einen Kredit vergibt, verleiht sie nicht das Geld eines anderen Kunden – sie schafft eine neue Einlage. So erklärt die Bank of England die Geldschöpfung und was das für deine Ersparnisse bedeutet.

Dieser Kanal wird von einem Ingenieur gemacht, nicht von einem Banker. Bildungsinhalt, keine Finanzberatung.
```
