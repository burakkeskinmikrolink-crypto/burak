## Español (İspanyolca)

**Başlık:**
```
¿Y si Estados Unidos dejara de usar efectivo?
```

**Açıklama:**
```
Cerca de uno de cada siete pagos en Estados Unidos todavía se hace en efectivo, y para millones de personas es casi el único medio. ¿Qué pasaría si el efectivo desapareciera? Quién gana, quién se queda fuera, si una tienda puede negarse legalmente a aceptarlo y qué aprendió Suecia sobre tener un respaldo.

Este canal lo hace un ingeniero, no un banquero. Contenido educativo, no es asesoramiento financiero.

3:18 ¿Puede una tienda rechazar el efectivo?
```

## Deutsch (Almanca)

```
Was wäre, wenn Amerika kein Bargeld mehr nutzen würde?
```

```
Dieser Kanal wird von einem Ingenieur gemacht, nicht von einem Banker. Bildungsinhalt, keine Finanzberatung.
```
