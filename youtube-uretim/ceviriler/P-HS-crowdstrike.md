## Español (İspanyolca)

**Başlık:**
```
La caída de CrowdStrike explicada: cómo una actualización detuvo millones de ordenadores
```

**Açıklama (geçici):**
```
En julio de 2024, una sola actualización defectuosa dejó millones de ordenadores con Windows en pantalla azul: aeropuertos, hospitales y bancos se detuvieron. Este es el sistema oculto de las actualizaciones automáticas y por qué falló a la vez en todas partes.

Este canal lo hace alguien que trabaja dentro de un centro de operaciones de red móvil.

FUENTES

```
